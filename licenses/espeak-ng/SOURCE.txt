M01 Unicode port and generated tables

Upstream: https://github.com/espeak-ng/espeak-ng
Commit: ba90c8e9f440ad544f674a790bb5f53878b6ffc5

src/core/unicode.js ports behavior from src/libespeak-ng/encoding.c and
common.c, and consumes generated ucd-tools classification/case data.
Original copyright notices remain in the pinned corresponding-source archive.
The modified pure-JavaScript implementation is licensed GPL-3.0-or-later.

data/unicode/tables.js is generated by tools/build-unicode/ from the pinned
src/ucd-tools/src/{categories,proplist,ctype,case}.c and include/ucd/ucd.h.
The exact source hashes and generated file hash are in data/unicode/manifest.json.
Unicode version: 11.0.0. ucd-tools is GPL-3.0-or-later; Unicode data additionally
carries the copyright/permission notice copied verbatim in COPYING.UCD.txt.
COPYING.txt is copied verbatim from src/ucd-tools/COPYING.

Build-time C adapters and runtime generated data are separate. No upstream
C library is required at JavaScript runtime. These licenses also accompany
the local source companion archives generated by npm run probe:source.
