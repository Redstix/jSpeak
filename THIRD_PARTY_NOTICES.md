# Third-party provenance

## eSpeak NG (reference tools and probe 0.4.x data)

- Source: https://github.com/espeak-ng/espeak-ng
- Pinned commit: see `upstream.json`.
- Upstream root `COPYING` contains GPL version 3. Other upstream files include `COPYING.APACHE`, `COPYING.BSD2`, `COPYING.UCD`; file-specific notices must be preserved when porting or redistributing their content.
- Probes 0.1.0–0.3.1 contained only locally generated diagnostic assets. Probe 0.4.0 additionally bundles six unchanged compiled data/voice files and a C-generated reference WAV. Paths, hashes, source commit, retained resources and incomplete language-dependency scope are recorded in `tools/build-data/source-lock.json` and [DATA_PACK.md](docs/DATA_PACK.md).
- The four upstream license texts are copied unchanged into `apps/vela-probe/src/common/licenses/espeak-ng/` and included in the RPK. File-specific notices remain in the complete source; the English rule source expressly specifies GPLv3-or-later. No upstream source or data notice has been replaced.
- `npm run probe:source` creates local corresponding-source companions under `artifacts/probe-<version>-sources/`: the clean pinned upstream source, the actual current project sources (including uncommitted changes), an upstream Git bundle for offline restoration of the exact commit, and a per-file/hash manifest. Deliver these companions with the RPK; they include the build/packaging scripts, lock files, tests and documentation. No keys, installed dependencies or device photos are included by the normal ignored-file rules. Restoration instructions are in [SOURCE_BUNDLE.md](docs/SOURCE_BUNDLE.md).
- Internal trace tooling applies a versioned C instrumentation patch in an isolated build tree. The patch and build scripts are part of the project source companion; the clean upstream archive supplies the original sources.
- This is provenance for the diagnostic delivery, not a declaration that the future complete TTS product's dependency/license audit is finished.

## Pure JavaScript Unicode primitives and generated Unicode 11.0.0 data

- `src/core/unicode.js` ports the pinned `encoding.c` UTF-8 decoder and `common.c` encoding, classification and simple case behavior under GPL-3.0-or-later. Source mappings and supported boundaries are documented in [UNICODE.md](docs/UNICODE.md).
- `tools/build-unicode/` compiles a development-only exporter against the pinned ucd-tools sources and generates `data/unicode/tables.js`. The data is derived from ucd-tools and Unicode 11.0.0, not from the host JavaScript Unicode implementation. `data/unicode/manifest.json` binds the upstream commit, original file hashes, exporter hash and generated bytes.
- Unmodified ucd-tools GPL and Unicode copyright/permission texts are retained in [licenses/espeak-ng/](licenses/espeak-ng/SOURCE.txt). The original copyright notices also remain in the complete upstream source companion. These new runtime sources and generated tables are included in the project source archive; they are not part of the probe 0.4.x RPKs.

## Vela build tooling

- `apps/vela-probe/package-lock.json` records npm dependencies and integrity hashes.
- `aiot-toolkit` 2.0.5 and `@aiot-toolkit/jsc` 1.0.9 are build-only dependencies. Installation reported 14 advisories (3 low, 11 high) on 2026-10-02; the 2026-10-05 install of the locked dependency tree reports 20 (3 low, 17 high). No blind `npm audit fix --force` or toolkit upgrade was applied. Review transitive licenses/security advisories before production use; do not expose the development server to untrusted networks.
- Debug RPK uses the toolkit's standard development certificate. No device key has been extracted or included in source control.

## Probe assets

`apps/vela-probe/tools/generate-assets.mjs` still generates the local icon, synthetic resources and 440 Hz tone. `tools/build-data/build.mjs` separately generates the real upstream data resources and the 22050Hz “Hello world” reference described above. The reference speech is generated by the pinned C implementation, not by a recording service or an external TTS engine.
