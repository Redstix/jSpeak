## 构建入口

- `tools/build-vela-tts-profiles/build.mjs` 改为 profile 驱动：en 使用 `apps/vela-probe/src/common/espeak`，cmn 使用 `artifacts/cmn-language-pack`。
- 每个 profile 生成专属 `DATA_ASSETS`（文件清单、URI、hash32、字典 manifest、语言、固定文本），页面与 `tts-service` 不再硬编码英文。
- 构建时逐例合成参考 WAV：en `Hello world.` 23,190 样本；cmn `你好，世界。` 32,822 样本，并与固定 C oracle SHA256 比较。
- 静态校验：versionName/Code、variant A、语言、runtime、数据字节、六个运行时文件、页头/构建戳、无构建期材料与预生成音频。
- `npm run tts:build` 构建两个包；`-- --reuse-stamp --reuse-existing-rpk` 用于同一构建戳下只补缺失包。

## Node 性能（5×25 成对）

固定输入：en `Hello world.`、cmn `你好，世界。`；每轮 25 次，共 5 轮；初始化每次新建 synthesizer，合成使用即时 scheduler，测量完整 PCM16 WAV。JSON：[2026-10-17-node-synthesis-benchmark.json](2026-10-17-node-synthesis-benchmark.json)。

| 指标 | en-us | cmn |
|---|---:|---:|
| 初始化 min / median / max | 1.679 / 2.142 / 40.153ms | 9.008 / 11.002 / 57.792ms |
| 合成 min / median / max | 16.888 / 23.435 / 282.633ms | 19.517 / 29.315 / 77.244ms |
| RTF min / median / max | 0.016058 / 0.022283 / 0.268739 | 0.013112 / 0.019694 / 0.051893 |
| 输出样本 | 23,190 | 32,822 |
| 输出 SHA256 | `db5fdc36…4fdb1` | `47e0c36e…cc9b1` |

en 的 282.633ms 是单次异常值；median/min/max 原样保留，不作为设备或稳定上限。Node/V8 数字不代表 QuickJS/Vela。
