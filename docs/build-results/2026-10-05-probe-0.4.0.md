## 本轮仍需设备确认

1. en_dict/phondata 全读，32768 字节分页、高偏移、跨页、末尾与 EOF。
2. 候选同时驻留、分块组装、首次/重复 I/O 和 hash 成本；可见 backing bytes 不等于 heap。
3. 22050Hz 包内与 internal 语音实际出声；append/position 与头回填是否保留全部字节。
4. 取消、前后台、迟到回调、BUSY 解除和临时文件清理。

逐项操作与反馈模板见 [探针 README](../../apps/vela-probe/README.md)。探针不是 JS TTS 引擎，记录的 Oracle WAV 听感不能证明 JS 合成正确或实时可用。
