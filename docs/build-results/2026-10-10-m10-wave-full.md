## 边界与未支持项

- 观察器仅为本轮把 `N_WCMDQ` 扩为4096以捕获完整逻辑命令；原170项运行时队列的满队 resume、背压和取消调度未验收，进入 M11。
- 首发 profile 未使用的命令仍显式 unsupported：`WCMD_KLATT`、`WCMD_KLATT2`、`WCMD_VOICE`、`WCMD_MBROLA_DATA`、`WCMD_FMT_AMPLITUDE`、`WCMD_SONIC_SPEED`、`WCMD_PHONEME_ALIGNMENT`。
- 当前 en-us 语料 echo 与 breath 为零；非零 echo、非零 breath/随机滤波虽已按 C 语义实现，但没有 C/JS exact 覆盖，不能宣称已验收。
- 本轮输入为 C 观察到的完整 Generate 命令计划和 voice/frame 状态；M11 仍需将有界运行时、队列和完整文本流水线集成起来。
