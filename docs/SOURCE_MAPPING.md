# Source mapping

目前没有已核验的上游到 JS 映射。不得把示例文件名或行号当作事实。

锁定上游后每项映射记录：

- upstream commit、源路径、符号名（行号仅为辅助）；
- 读取/写入状态及调用阶段；
- JS 路径与符号；
- 输入数据 artifact 与转换规则；
- trace 观察点、回归 case ID；
- 支持范围、未移植分支及原因。

数据管线优先复用固定版本的上游编译器，读取或转换其产物。运行时不解析 phsource；也不默认自造新 DSL 编译器。继承 flatten 必须依据上游语义核验，不提前判断正确或错误。

单语言裁剪必须保留所有间接依赖；构建输出资源依赖闭包与 exclusions manifest。开发数据结构可保留调试信息，生产格式在正确性及设备验证之后冻结。
